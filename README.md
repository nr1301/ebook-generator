# e-book 생성기 (시험판)

교과서 PDF와 수업 자료 폴더를 넣으면, 쪽마다 자료 버튼이 자리까지 잡혀 붙은 교사용 e-book 초안을 만들어 주는 브라우저 도구입니다.
설치·서버 없음. 파일은 브라우저 안에서만 처리되고 어디에도 올라가지 않습니다.

- **바로 쓰기**: 이 저장소의 GitHub Pages 주소 → 「저작기」
- 크롬·엣지 최신판 권장 (폴더 고르기·저장)

## 들어 있는 것
| 폴더 | |
|---|---|
| `authoring/` | 저작기 — 프로젝트 만들기(PDF 변환), 자료 폴더로 초안 만들기(쪽 찾기·자리 잡기), 속성·전역 버튼·저장 |
| `authoring/name-finder.html` | 자료 이름 찾기 — 쪽번호 없는 자료를 규칙 이름으로 복사 |
| `viewer/` | 교사 화면 — 펼침 보기, 자료 열기(링크는 새 탭, 발표 파일은 받아서 열기, 문서는 미리보기) |
| `common/` | 인증·CMS 어댑터 (엠티처 연동 자리) |

샘플(교과서·수업 자료)은 저작권 때문에 포함하지 않습니다. 사내 체험판 폴더를 쓰세요.

## 파일 이름 규칙
`{교과서 쪽}_{자료코드}_{이름}[_@CMS코드].확장자` — 코드: TG 지도·원본 / PT 수업 PPT / WS 활동지 / AN 평가 / VD 영상 / IM 그림 / EX 외부·실행.
규칙이 없는 이름도 내용·그림으로 쪽을 찾아 붙입니다(시험 기능).

## 오픈소스
- [pdf.js](https://github.com/mozilla/pdf.js) 3.11 — Apache-2.0 (`authoring/vendor/pdf*.js`)
- [opencv.js](https://github.com/TechStark/opencv-js) 4.12 — Apache-2.0 (`authoring/vendor/opencv.js`)
